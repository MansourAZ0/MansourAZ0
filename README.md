### Music

- **Ajnas** — Oud practice app for desktop. A Rust audio engine listens through the mic, detects the pitch of each note in real time and maps it onto a 24-step quarter-tone scale, while a Tauri and React UI shows it on the fingerboard
- **Ajnas for iOS** — Same thing on iPhone, plus slowing down and looping songs to play along
- **Watar** — An oud tuner that understands quarter-tones. Streams mic audio through a pitch detector and shows how many cents you are from the nearest Arabic note
- **naghma-core** — The Rust engine behind Watar and Ajnas. Turns a frequency into a note name, octave and cents offset on a 24-tone grid, with oud tunings and maqam data built in
- **pitchforge-rs** — Pitch detection in Rust using the YIN algorithm. Finds the fundamental frequency of a single note and reports when it can't find a reliable one
